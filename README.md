# Recycling A to Z ♻️

A web application that helps users identify how to dispose of waste correctly and find nearby recycling facilities.

## Overview

Recycling A to Z is a recycling assistance platform designed to make waste disposal easier and more accessible.

Users can upload images of items they want to dispose of and receive disposal guidance through image analysis using the Google Vision API. The application also integrates Google Maps to help users locate nearby recycling facilities, such as battery and glass recycling points.

When users need additional help, they can ask questions and share photos with the community, where other users can contribute information through comments.

## Key Features

- **Image-Based Waste Identification:** Uses the Google Vision API to analyse images and assist users with waste disposal.
- **Recycling Facility Locator:** Integrates Google Maps to help users find nearby recycling points.
- **Community Platform:** Allows users to share questions and photos about recycling.
- **Comment System:** Enables users to exchange information and provide answers through comments.
- **User Authentication:** Provides login functionality.
- **Form Validation:** Uses JavaScript to validate user input.

## Tech Stack

- **Backend:** Java, Spring Framework
- **Frontend:** HTML, Thymeleaf, JavaScript
- **Database Architecture:** Spring Data components, including entities and repositories
- **APIs:** Google Vision API, Google Maps JavaScript API
- **Asynchronous Requests:** AJAX
